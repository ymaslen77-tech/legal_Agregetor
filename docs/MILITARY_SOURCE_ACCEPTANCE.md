# Автоматическая юридическая сверка военного права

## Цель

Применять один и тот же проверяемый стандарт ко всем 143 ситуациям и связанным 121 генераторам. Отдельная подпись юриста **не обязательна** для фактов, успешно подтверждённых источниками. Разработка и тестирование несвязанных материалов не блокируются из-за отдельных спорных пунктов.

## Что именно сравнивается

Единица приёмки — **конкретное юридически значимое утверждение**, а не страница сайта и не одна лишь ссылка на закон. Для каждого утверждения фиксируются:

1. утверждение и контекст (вид службы, период действия, субъект, применимый правовой режим);
2. минимум **два независимых издателя** с точными адресами страниц и проверенными текстовыми фрагментами; третий источник полезен, но не обязателен;
3. название акта, статья/пункт, редакция, дата проверки;
4. результат и наличие противоречий; при изменении закона проверка обновляется.

Разные страницы одного издателя не равны двум независимым источникам. Поисковая выдача, один лишь HTTP 200, ссылка на главную страницу, устаревшая перепечатка и совпадение общего названия **не подтверждают** содержание нормы.

## Автоматическое решение

| Условия | Статус |
| --- | --- |
| 2–3 независимых источника подтверждают один и тот же тезис и область его действия | `VERIFIED_OFFICIAL` при наличии официального подтверждения, иначе `VERIFIED_REPUTABLE` |
| Официальная действующая редакция подтверждает тезис, один из неофициальных источников даёт другое толкование | Приоритет официальной редакции; отклоняющуюся перепечатку не использовать как нормативный источник |
| Официальный текст **опровергает** исходный тезис | Не помечать ошибочный тезис проверенным; исправить его по официальному тексту и заново проверить |
| Два официальных источника противоречат друг другу из-за редакции или даты | `OFFICIAL_CONFLICT`, сверить действие во времени и специальные правила |
| Неофициальные источники расходятся и официальный не разрешает вопрос | `SOURCE_CONFLICT` |
| Не хватает доказательств или источник временно недоступен | `NEEDS_SOURCES`, доукомплектовать подтверждения |

**Автоматическая приёмка не означает разрешение на подачу персонального документа.** Реквизиты, сроки, полномочия, адресат, подсудность и приложения должны соответствовать конкретной ситуации пользователя. Генераторы без этих данных сохраняют `filingReady=false` и предупреждение «Черновик».

## Порядок работы

- GitHub Actions повторно проверяет зафиксированные фрагменты и собирает очередь источников для 143 ситуаций.
- Проверка доступности кандидатных ссылок — только диагностика. Никакой автостатус «проверено» от одного открытия страницы не выдаётся.
- Приоритет — официальный опубликованный текст в действующей применимой редакции.
- Результат фиксируется по каждому тезису отдельно; другие сценарии можно продолжать, тестировать и выпускать в безопасном информационном режиме.
- Сведения о медицинском состоянии, личных фактах, документах и процессуальных действиях пользователя не становятся публичными ни в CI, ни в JSON-отчётах.

Связанные модули: `src/data/military-source-verification.ts`, `scripts/audit-military-sources.ts`, `scripts/audit-military-source-candidates.ts`.
