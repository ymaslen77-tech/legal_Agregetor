# Проверка уведомления GitHub → Coolify

Дата: 27 октября 2026 года.

Этот файл создан исключительно в отдельной технической ветке для проверки доставки GitHub `push`-события через Webhook. Рабочую ветку `main` и код сайта он не изменяет. Автоматическое развёртывание приложения `pravopoisk-web`, привязанного к `main`, не требуется.

После успешной проверки доставки удалить тестовую ветку можно отдельной операцией.
