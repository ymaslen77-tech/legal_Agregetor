# Этап № 3 — реестр целевых документов для 121 ситуации

**Дата:** 29.10.2026  
**Проект:** ПравоПоиск / военное право  
**PR:** #25 (Draft), ветка `feature/military-rebuild-from-zero-20261027`  
**Результат:** проектный реестр `src/data/military-document-target-matrix.ts`; тест `src/data/military-document-target-matrix.test.ts`.

## Сводка

- Всего 20 категорий, 143 ситуации.
- 22 ситуации — информационные; генерация документа для них не предполагается.
- 121 документная и смешанная ситуация получила **индивидуальный целевой тип и название документа**, правовой вопрос, предполагаемого адресата, необходимую доказательственную базу и ограничение выбора.
- 38 ситуаций имеют условную альтернативу (например, внесудебная жалоба / административный иск либо процессуальное ходатайство / жалоба). Альтернативу **нельзя выбирать автоматически**.
- 18 ранее существовавших прототипов черновиков не затрагивались.
- 103 документа пока не имеют даже прототипа генератора; это задача этапов № 4–8, а **не** выполненная генерация.
- Статус всех целевых форм: `EDITORIAL_TARGET_PENDING_LEGAL_REVIEW`, `generationEnabled=false`, `filingReady=false`, `requiresLegalReview=true`.
- История версий, `DOCUMENT_RESULT_V1`, PDF/DOCX и канонические страницы пока не реализованы этими изменениями; это предмет следующих этапов.

## Правила выбора и приёмки

1. Выбор ситуации уже определяет предмет обращения; пользователь не должен повторно вводить этот вопрос. Потребуются только действительно нужные для конкретного документа факты и реквизиты.
2. Вид службы, дата, ведомство, компетенция адресата, наличие письменного решения, сроки, право на выплату и специальный правовой режим должны проверяться до выбора итогового документа.
3. Отсутствие документа, который требует информационная ситуация, — не ошибка покрытия.
4. Судебный документ из альтернативной ветки нельзя формировать по одному лишь желанию пользователя; нужна процессуальная квалификация по применимому кодексу и подсудность.
5. При угрозе жизни и здоровью медицинская помощь не может быть отложена ради заполнения рапорта.
6. В уголовных процедурах нельзя предлагать произвольную общую жалобу вместо документа с учётом статуса участника дела и требований УПК РФ.
7. Для региональных выплат необходим конкретный акт субъекта, а для федеральных — точный вид выплаты и действующая редакция.
8. Любой прототип остаётся черновиком, не имеющим юридического утверждения; на сайте запрещено выдавать матрицу за готовый к подаче документ.
9. Перед созданием генератора эксперт должен подтвердить: правовые основания, адресата, требуемые поля и приложения, тип документа и альтернативные ветки; далее тестируется `DOCUMENT_RESULT_V1`, версионность и PDF/DOCX.
