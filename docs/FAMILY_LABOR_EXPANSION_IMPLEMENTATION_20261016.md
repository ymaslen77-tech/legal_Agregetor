# Семейное и трудовое право: реализация плана пробелов

Дата: 16 октября 2026. Ветка PR №8, без изменений main, Neon и Vercel.

## Выполненная инженерная часть
- Добавлен внутренний машинно читаемый план: 8 новых маршрутов (3 семейных, 5 трудовых), 12 расширений существующих маршрутов (4 семейных, 8 трудовых), 3 межотраслевых перехода.
- Для сценариев созданы обязательные вопросы анкеты: статус, факты, даты, документы, цель и дополнительные ситуационные признаки. В случае семейной угрозы помощь не обусловлена заполнением личных данных.
- Проверка обязательных полей, недопустимых значений и ограничения длины введённых сведений. Даже полностью заполненная анкета не может авторизовать генерацию и подачу до правовой проверки.
- Внутренний единый каталог теперь связывает планы с семейным и трудовым правом, не включает их в публичный навигатор. Базовые 29 семейных и 14 трудовых маршрутов сохранены.

## Не закрыто
- Сверка действующих редакций норм и судебной практики на официальных источниках, срока обращения и подсудности для каждого отдельного кейса.
- Реальные документы, юридические валидаторы, приёмка PDF/DOCX, версия в кабинете и негативные тесты содержимого.
- Согласование исправлений из отдельного PR №7 с PR №8 до любой интеграции.

## Важное ограничение
Числа совпадений в Q&A из аудита — пересекающиеся текстовые сигналы, а не уникальные юридические дела.
Каждая запись плана помечена PENDING_OFFICIAL_SOURCES, NOT_IMPLEMENTED, publicEnabled=false, filingReady=false.
Программа не создаёт новый публичный URL или готовый к подаче документ. Жилищное право в этом пакете не изменено.
