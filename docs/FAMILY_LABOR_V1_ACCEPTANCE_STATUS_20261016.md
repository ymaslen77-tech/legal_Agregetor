# Семейное и трудовое право — внедрение маршрутов V1
Дата: 16.10.2026. Рабочий черновой PR №8. Этот отчёт разграничивает реализованный код и незакрытую юридическую приёмку.

## Реализовано
- Старые 43 маршрута (29 семейных, 14 трудовых) и их канонические URL сохранены.
- Добавлено 8 самостоятельных маршрутов: имущество незарегистрированных сожителей, опека над совершеннолетними, срочная семейная защита; беременность и роды, вахта и командировки, совместительство и совмещение, несовершеннолетние работники, иностранные работники.
- 12 расширений прежних маршрутов: возражения на приказ, неустойка, исполнение, образование ребёнка; неоплачиваемый отпуск, дистанционная работа, охрана труда, неполное время, учебный отпуск, отказ при приёме, простой, предпенсионные гарантии.
- 3 межотраслевые связи зафиксированы в проектном каталоге. Это не завершённые генераторы социальной, жилищной или образовательной отрасли.
- 51 маршрут в V1-реестре. Дополнения исходных страниц открываются при FAMILY_LABOR_PREVIEW=1, который не следует включать в Production.

## Технический стандарт
1. Ситуация, сценарий, canonical URL и query scenario.
2. Сценарная анкета с обязательными фактами, развилками по статусу и срокам.
3. Первичная правовая проверка применимости и документов. Все неподтверждённые выводы блокируются.
4. Персональный предварительный чек-лист, не заявление, не иск.
5. Единый DOCUMENT_RESULT_V1: UUID, дата, источник DETERMINISTIC, filingReady=false, requiresLegalReview=true.
6. PDF A4 через pdfmake; DOCX через стандартный экспорт. Каждая новая версия независима.
7. Опциональное шифрованное сохранение через авторизованный API личного кабинета после отдельного действия пользователя.
8. Негативные тесты: неполные анкеты, просроченные возражения без объяснения, экстренные сценарии, несуществующие маршруты, запрет filingReady.

## Юридические первоисточники для последующей проверки
- Семейные: СК РФ статья 115, ГПК РФ статьи 128–129, Закон № 229-ФЗ статья 121; уточнить редакцию, адресата, компетенцию и сроки.
- Трудовые: ТК РФ статьи 63, 93, 128, 157, 255, 261, 265–269, 282, 312.1, 327.1 и специальные нормы по каждой ситуации.
- СФР: https://sfr.gov.ru/grazhdanam/semyam_s_detmi/posobie_po_beremennosti_i_rodam/
- Государственная инспекция труда: https://git86.rostrud.gov.ru/news/1487972.html
- Нормативные акты: https://pravo.gov.ru/

## НЕ ГОТОВО К ЮРИДИЧЕСКОМУ РЕЛИЗУ
- Полноценные проверенные генераторы исков, жалоб, возражений и расчётов для всех новых сценариев.
- Содержательная юридическая приёмка норм, исключений, срока, подсудности, госпошлины по каждому случаю.
- Примирение правок из отдельного PR №7 и PR №8, дополнительные отрицательные тесты на выборках Q&A.
- Публикация на основном сайте и применение миграций: никаких изменений Neon, main, Vercel Production не выполнялось.

**Решение:** технические чек-листы доступны для тестирования; релиз как юридически готовых документов не разрешён.
