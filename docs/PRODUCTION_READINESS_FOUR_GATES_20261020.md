# ПравоПоиск — проверка четырёх оставшихся задач (20.10.2026)

## Фактическое состояние
1. **Neon**: project `pravopoisk` (`purple-sun-53026244`) на `free_v3`. Попытка `SELECT 1` / запрос метаданных по SQL возвращает `HTTP 402 / exceeded the quota`. Восстановление доступа требует действий владельца тарифа; SQL/данные не менять и не удалять.
2. **Вопросы и юристы**: `/questions/`, `/lawyers/` отвечают HTTP 200, но `robots=noindex,follow`. Карты `sitemap-questions.xml`, `sitemap-lawyers.xml` пустые во время недоступности DB. **Не поднимать index принудительно**: индексация разрешается только при наличии действительных качественных публичных данных; последующая проверка SEO-состояния необходима после восстановления БД.
3. **API городов**: раньше при сбое БД возвращал HTTP 200 + `{"cities":[]}` из repository fallback. В PR endpoint читает реальные активные города напрямую; при сбое возвращает **HTTP 503** + `CITY_DIRECTORY_TEMPORARILY_UNAVAILABLE`, `Cache-Control:no-store`, `Retry-After:30`. UI уже предлагает повторное получение при non-2xx. При реально пустой БД сохраняется HTTP 200 и пустой список. Никакие выдуманные города не публикуются.
4. **Юридическая приёмка 32 добавленных сценариев**: автоматический реестр `scripts/audit-family-labor-release.ts` указывает `expertSignOff=NOT_GRANTED`, `filingReady=false` для каждого сценария. Это корректная защита. Не снимать её по результату CI. Нужны индивидуальная правовая проверка по 11 критериям, официальные редакции норм, экспорт PDF/DOCX и подписанное согласование для каждого случая.

## Условия завершения
- Neon SQL-запрос для чтения успешен, проверены количества реальных записей, целостность и доступность БД в Vercel Production.
- `/api/public-cities/` возвращает HTTP 200 со списком активных городов; тест пустой таблицы и тест отказа БД дают различные статусы.
- `/questions/`, `/lawyers/`, карты сайта проверены после восстановления БД; качество и модерация удовлетворяют правилам `canIndexQuestionPage` и `canIndexLawyerProfilePage`, лишние `noindex` не удалять вручную.
- По 32 сценариям закрыта юридическая матрица со ссылками на первичные действующие нормы, датами, видом документа, подсудностью/сроками и результатами экспертной приёмки. До этого на публичном сайте оставлять ознакомительный режим.

Это протокол не является доказательством завершения задач 1, 2 и 4.
