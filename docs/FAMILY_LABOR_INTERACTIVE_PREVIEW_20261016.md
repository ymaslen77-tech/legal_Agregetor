# Семейные и трудовые маршруты: интерактивный стенд доработок

**Дата:** 16.10.2026. **Статус:** рабочий PR №8; текущие 43 опубликованных маршрута и их URL сохраняются.

## Реализованная итерация
- Переведён машинно-читаемый каталог 23 задач (8 новых маршрутов, 12 дополнений и 3 перехода) в интерактивные пошаговые анкеты на **существующих страницах**; создан общий компонент FamilyLaborExpansionPreview и серверная точка подключения через layout.
- Для локальной/тестовой сборки выставить **только в изолированной среде** FAMILY_LABOR_PREVIEW=1. Без флага UI новых сценариев не отображается. Не выставлять этот флаг в Production.
- Для 4 семейных P1-ситуаций введены специализированные алгоритмы первичной проверки: отмена приказа (ГПК 128–129), неустойка (СК 115), обращения при бездействии приставов (Закон №229-ФЗ, статья 121), срочная защита. Также отдельные правила для сожительства и опеки над взрослыми, для семейного/образовательного спора и части трудовых тем.
- Форма не отправляет персональные сведения по сети и не сохраняет их в базе или личном кабинете. Для новых кейсов не разрешается генерация исков, жалоб, расчётов, PDF/DOCX, либо маркировка «готово к подаче». Результат — **предварительный чек-лист**.
- При непосредственной угрозе жизни помощь показывается без анкеты; код не блокирует экстренное обращение.
- Защитные автоматизированные тесты проверяют неполные анкеты, запрет на документы, переходы и специальные сценарии.

## Источники для ревизии
- ГПК РФ, статьи 128–129: официальный портал https://pravo.gov.ru/proxy/ips/?docbody=&nd=102078828; важно отличать дату вынесения приказа от даты получения.
- СК РФ, статья 115: проверять действующую редакцию и применимый период, основание обязательства и вину; ручная проверка расчёта обязательна.
- Минюст России: https://www.minjust.gov.ru/ru/appeals/faq/690/ — порядок обжалования ФССП.
- Применимость каждой нормы, актуальная судебная практика, локальная подсудность и полноценная юридическая приёмка новых документов ещё **не выполнены**.

## Следующее ограничение
Сценарии разрабатываются по сигналам в 43 335 вопросах двух направлений. Текстовые совпадения пересекаются и не означают, что алгоритм уже правильно квалифицирует каждый случай.
Пользовательские PDF/DOCX, встраивание новых материалов в существующие генераторы и выпуск в Production — отдельная работа после отрицательных юридических тестов. PR №7 нужно согласовать с PR №8 до общей интеграции.
