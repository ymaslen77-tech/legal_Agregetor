# Семейное и трудовое право — дополнительная итерация подготовки обращений

Дата: 18.10.2026. Ветка PR №8, **без публикации**.

## Что улучшено
Для пяти ранее ограниченных чек-листами случаев добавлены детерминированные проекты **информационных и организационных обращений**, не судебных исков:
1. maternity-leave/benefits — запрос об оформлении пособия по беременности и родам (статья 255 ТК РФ);
2. shifts-and-business-trips/expenses — запрос по расходам с явным различением командировки, разъездной работы и вахты (статьи 168, 168.1, 302 ТК РФ);
3. secondary-employment/registration — запрос о документах и правовом режиме дополнительной работы: совмещение либо совместительство (статьи 60.1, 60.2, 151 ТК РФ);
4. alimony-enforcement/inaction — обращение стороны в ФССП об ознакомлении с материалами производства (статья 50 закона №229-ФЗ), **не жалоба**;
5. alimony-enforcement/balance — запрос стороне ФССП о постановлении о расчёте задолженности (статьи 50 и 102 закона №229-ФЗ), **не иск**.

Для документов ФССП обязательны подтверждённый статус стороны («взыскатель» или «должник») и факт возбуждения производства. При отсутствии данных о них генерация переключается на чек-лист. Не генерировать жалобу/иск автоматически. Для иных новых видов документов сохраняются соответствующие разграничители.

Всего: 30 экспортируемых исходов — **14 предварительных проектов и 16 чек-листов**; 2 сценария экстренной помощи не создают документов. Публикация, индексация, готовность к подаче и \`legalRegistryReviewedAt\` остаются заблокированы до индивидуальной юридической приёмки.

## Проверка
\`npm run test:route-standard\` включает регистры, данные Q&A, границы сценариев и негативные тесты. \`npm run audit:family-labor-files\` создаёт и проверяет 30 пар PDF/DOCX и метки юридической неприёмки. Это **техническая, не юридическая** проверка.
